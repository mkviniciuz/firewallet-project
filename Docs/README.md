# 📌 Projeto Carteira Digital — Desktop App

Aplicativo desktop para controle financeiro, com design moderno e arquitetura profissional.

## 🧱 Tecnologias Utilizadas
- **Electron** → Interface (Frontend)
- **Python** → Backend e regras de negócio
- **SQLite** → Banco de dados
- **C (Native Module)** → Cálculos financeiros otimizados
- **IPC (Electron ↔ Python)** → Comunicação entre camadas

## 🎯 Objetivo
Oferecer uma experiência fluida de gerenciamento financeiro pessoal, com:
- Registro de entradas e saídas
- Dashboard com gráficos e indicadores
- Categorias personalizáveis
- Autenticação segura (login, hashing de senha)
- Base modular e escalável para expansão futura
